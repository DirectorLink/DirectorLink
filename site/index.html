Direct to Director. End-to-end integration. Open source.

DirectorLink is an open-source driver for Control4 and an app for phones and computers. The driver gives your home a standard local REST API, described by OpenAPI, with its own access role for every device and app. Each phone or computer pairs once with a one-time code from Composer — your installer can read it out for you.

Open the app API console Source on GitHub

How it works

  1. 1

    Install the driver

    Add the DirectorLink driver to the Control4 project. It serves the API on your home network, on port 41999.

  2. 2

    Open the app

    On your phone or computer, open the app and enter the controller's address.

  3. 3

    Enter the pairing code

    Type the 8-digit code from Composer (DirectorLink → Actions → New Pairing Code) — the installer can read it for you. A code lasts 15 minutes and works once.

What you get

  • Local and direct

    The browser talks to the controller over your LAN. No cloud relay, no port forwarding.

  • A real API

    Rooms, lights, climate, blinds, cameras and doors as plain REST resources, described by OpenAPI 3.1.

  • Roles per device

    viewer, member, doors or admin — each app and script gets only what it needs, and can be revoked.

DirectorLink is an independent project, not affiliated with Control4 or Snap One.
