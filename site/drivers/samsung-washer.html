DirectorLink Drivers

DirectorLink · Samsung Washer for Control4

A free, open-source Control4 driver for Samsung Wi-Fi washing machines: the washer's state, programme, time left and finish time on a Washer tile, events when a cycle starts, pauses and finishes, and safe Pause, Resume, Stop and Start. It works through Samsung's SmartThings cloud, with no extra hardware and no subscription.

Free. No subscription, no license key, no account with us.

Download the beta Release notes and checksums Source and full guide

Made by DirectorLink, the open-source management layer for Control4 homes. Works on its own: DirectorLink is not required.

Beta: field reports wanted. 1.0.0-beta.1 passes its tests against recorded SmartThings answers from real Samsung washers, but it has not run on a real washer yet. The first model to test is the WW90CGC04DAH (Series 5 ecobubble, 9 kg). If you install it, please send its Print Diagnostics.

What you get

Feature Control4 app Programming
Washer tile Its icon shows off, ready, running, paused, finished or an error; a tap reads the washer again –
State, programme, time left, finish time, progress The tile's text, for example Washing - Eco 40-60, 1 h 40 min left, done 14:32 Variables, State conditional
Spin, temperature, rinses, kids lock, delay end, power – Variables, Composer properties
Cycle Started, Paused and Finished; Error – Events (Cycle Finished once per cycle)
Smart Control (remote control) on or off – Events, variable, conditional
Pause, Resume, Stop – Commands and Composer actions
Start – Command, only while Smart Control is on at the washer

A tap on the tile only reads the washer again: it never pauses, starts or stops it, so a child or a pocket can't stop a wash. Start and Resume are sent only when the washer itself says Smart Control is on, read just before sending; otherwise they are refused with a clear reason, and the driver never retries by itself. The driver never changes the programme, temperature or spin.

What it needs

  • A Samsung washing machine on Wi-Fi, added to the SmartThings app.
  • A Control4 controller with internet access, on OS 3.3 or newer, and Composer Pro.
  • For setup: the login of the Samsung account the washer is registered to, and about 10 minutes.
  • Tested offline against recorded SmartThings answers from a DA_WM_TP1_21_COMMON washer (the platform of the WW5000C series, which includes the WW90CGC04DAH), a TP2 front-loader, an A51 washer-dryer and two older TP6X washers. Not yet on a real washer: that is what the beta is for.

Setup in four steps

  1. 1

    Add the driver

    In Composer Pro: Driver → Add or Update Driver or Agent, and select DirectorLink-Samsung-Washer.c4z. On the Search tab, tick Local, search for DirectorLink and add DirectorLink · Samsung Washer to the room.

  2. 2

    Give it a token, once

    Make a Personal Access Token at account.smartthings.com/tokens with the washer's Samsung account and every box under Devices, Locations and Apps ticked, and paste it into the driver. It is used only to set up the driver's own sign-in.

  3. 3

    Sign in once

    Run the actions Create OAuth App and Show Authorization URL, sign in with the washer's Samsung account, and paste the whole address you land on into Authorization Code. The driver renews its access from then on.

  4. 4

    Show the tile

    One washer is picked by itself; with more, choose it in Select Washer. Make the Washer tile visible in the room's Navigator settings.

The steps are the same as for DirectorLink · Samsung Refrigerator: a project that has it still makes a token and signs in once for the washer. Save the OAuth Client ID and Secret the driver fills in: SmartThings never shows the secret again. Each step, and what each message means, is on the driver's Documentation tab in Composer and in the full guide.

Ideas for programming

  • Laundry's done

    On Cycle Finished, send a push notification, or flash the hall lights.

  • Forgotten laundry

    On Cycle Finished, start a 30-minute timer; if State is Finished when it ends, notify again.

  • Quiet hours

    A scheduled event at 22:00 runs Pause if State is Running.

Privacy and support

  • The driver talks only to Samsung's SmartThings service, with the access you grant it. It sends nothing to DirectorLink and collects no usage data. The sign-in happens in your browser, which lands on httpbin.org to show you the one-time code. Tokens stay in Control4's encrypted driver storage and are never written to the log or shown, Print Diagnostics included.
  • Keep the exact file name: a browser's … (1).c4z copy installs as a separate driver instead of updating. An update keeps the settings and the sign-in.
  • Testing the beta: with Debug Mode on, run Print Diagnostics with the washer on, and once more during a cycle, and check that the tile, State, Programme, Time Remaining and Finish Time match the washer's display. Try Start once with Smart Control off: it must be refused.
  • Community-supported, best effort. Report a problem or how the beta went with the Print Diagnostics outputs, the washer's model number (on the label inside the door) and your Control4 OS version. Never post tokens or the Client Secret.
