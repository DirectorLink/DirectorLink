DirectorLink · Samsung Refrigerator for Control4

Free, open-source Control4 driver for Samsung Wi-Fi refrigerators. It works through Samsung's SmartThings cloud, with no extra hardware and no subscription.

Free. No subscription, no license key, no account with us.

Download the driver Release notes and checksums Source and full guide

Made by DirectorLink, the open-source management layer for Control4 homes. Works on its own: DirectorLink is not required.

What you get

Refrigerator status Tile: green when fine, amber when a door is open, red on a problem. Tap to refresh. –
Power Cool (fast cooling) Tile, tap to switch On, Off, Toggle; events; conditionals
Power Freeze (fast freezing) Tile, tap to switch On, Off, Toggle; events; conditionals
Sabbath Mode Tile, tap to switch On, Off, Toggle; events; conditionals

Temperatures, doors, FlexZone – Door Opened, Door Closed and Door Left Open events; variables

Power, energy, online – Offline and Online events, variables

The driver checks each feature on your refrigerator. What your model does not offer shows as Not available, and its tile is greyed out. Commands go through Samsung's cloud: the driver shows a change as done only once the refrigerator confirms it, usually within a few seconds, and fires Command Failed if it does not.

What it needs

  • A Samsung refrigerator on Wi-Fi, added to the SmartThings app.
  • A Control4 controller with internet access, on OS 3.3 or newer (tested on 4.2.1), and Composer Pro.
  • Tested live on an RF85T901335ML (SmartThings model TP2X_REF_20K). The offline tests also cover TP1X, Family Hub, one-door and older dongle-based models.

Setup in four steps

  1. 1

    Add the driver

    In Composer Pro: Driver → Add or Update Driver or Agent, and select DirectorLink-Samsung-Refrigerator.c4z. On the Search tab, tick Local, search for Samsung Refrigerator and add it to the kitchen.

  2. 2

    Give it a token, once

    Make a Personal Access Token at account.smartthings.com/tokens with every box under Devices, Locations and Apps ticked, and paste it into the driver. It is used only to set up the driver's own sign-in.

  3. 3

    Sign in once

    Run the actions Create OAuth App and Show Authorization URL, sign in with the refrigerator's Samsung account, and paste the address you land on into Authorization Code. The driver renews its access from then on.

  4. 4

    Show the tiles

    One refrigerator is picked by itself; with more, choose it in Select Refrigerator. Make the tiles you want visible in the room's Navigator settings.

Each step, and what each message means, is on the driver's Documentation tab in Composer and in the full guide.

Ideas for programming

  • Big grocery run

    A keypad button turns Power Cool on before the shopping goes in.

  • Door left open

    On Door Left Open (after 5 minutes by default), send a push notification.

  • Keypad lights

    Bind keypad buttons to a feature: their LEDs follow its state.

Privacy and support

  • The driver talks only to Samsung's SmartThings service, with the access you grant it. It sends nothing to DirectorLink and collects no usage data.
  • Updating: download the new release, mind the file name, and run Add or Update Driver again. Settings and sign-in are kept.
  • Community-supported, best effort. Report a problem with the Composer properties Driver Version, Model, Supported Features and Driver Status. Never post tokens or the Client Secret.
