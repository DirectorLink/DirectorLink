FIRST SETUP

Director address

Enter the Director address and the short Pairing Code shown in the C4Bridge Properties pane in Composer. The long owner credential stays hidden.

Example: 192.168.1.50 or director.local. API port: 41999

Enter this only when pairing a new browser. The code is never stored here and rotates after a successful pairing.
