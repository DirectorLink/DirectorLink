# C4Bridge v0.1.0-alpha.1

First public discovery build.

## Compatibility

- Minimum Director OS: **3.3.0**
- Intended for early testing on Control4 OS 3.3.x and newer

## Included

- Director OS version detection
- Director/project metadata discovery
- project hierarchy and room discovery
- full device discovery through DriverWorks
- proxy/protocol relationship normalization
- recognition of initial light/climate/cover proxy families
- unsupported-device fallback
- Composer-visible discovery diagnostics

## Not included yet

- device control
- LAN API
- authentication/pairing
- PWA
- scenes
- schedules
- automatic driver updates

## Test expectation

After installing the driver, its Composer Properties should report:

- Bridge Version: `0.1.0-alpha.1`
- Status: `Ready (discovery complete)`
- Director Version
- System Type
- Project Location
- Discovery Summary

This is an **alpha test release**. It performs discovery only and does not yet send control commands to other project devices.
