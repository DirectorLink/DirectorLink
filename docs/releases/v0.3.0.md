# C4Bridge v0.3.0

Approve new browsers and apps from the Control4 app — no Composer needed after installation.

## C4Bridge Access button

- The driver adds a **C4Bridge Access** button (a Control4 experience button) to the project.
- A client asks for access; the button turns orange; pressing it in the Control4 app within 2 minutes approves the request, the button turns green, and the client collects its API key once.
- The C4Bridge properties in Composer show what is waiting (**Access Request**).
- Control4 adds new buttons hidden in the app. When C4Bridge is added to a project it makes its own button visible in the **Security** section of its room, the same change Composer's Navigators view makes (`SET_SECURITY_DEVICE_ORDER` on the room, every other entry kept as it was). The Composer action **Show Access Button in App** does it again on demand, for example after moving the button to another room.

## API

- `POST /v1/auth/requests` — ask for a key (only one request waits at a time; at most 5 per 10 minutes)
- `GET /v1/auth/requests/{requestId}` — status, and the key once after approval
- `DELETE /v1/auth/requests/{requestId}` — cancel
- The request id is the only way to collect the key and is never written to the log.
- `POST /v1/auth/pair` with the Composer pairing code still works as a fallback.

## Web app

**Request access** is now the main way to pair; the pairing code moved under "Use a pairing code instead". Offline mode and cross-platform checksums from the previous merge are included.

## Installing — remove and re-add once

C4Bridge is no longer a "combo" driver: like other Control4 button drivers, it is now a protocol device with one child proxy, the **C4Bridge Access** button (the Director does not create extra proxies for combo drivers). Because the device structure changed, updating from 0.2.x needs a one-time **remove and re-add** of C4Bridge in Composer. Stored API keys are removed with it, so each browser requests access again. Afterwards the project shows **C4Bridge** and its **C4Bridge Access** button, already visible in the Security section of its room in the Control4 app.

## Known issues

- KNX percentage dimming remains deferred (issue #11).
