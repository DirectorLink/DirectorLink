# DirectorLink v1.4.1

**Direct to Director. End-to-end integration. Open source.**

DirectorLink 1.4.1: the update notice gets a **Check now** button, and Settings shows the app's own version.

## Updates

- **Check now** (admins), in Settings → Controller, asks at once whether a newer DirectorLink is out, instead of waiting for the next check (about twice a day).
  - It shows *Checking…*, then the answer.
  - It asks at most once a minute. Pressed sooner, it says *You can check again in a minute* and does nothing.
  - The regular checks then count from it.
  - As before, only admin devices ask, and they ask GitHub directly, not through DirectorLink's servers.
- **App version:** Settings → Controller shows which version of the app this device runs, next to the DirectorLink version on the controller.

## Installing

- The app updates by itself; reload an app that was open.
- The driver is the same as 1.4.0 apart from its version number. Updating it in Composer is optional.

## For developers

- `app/js/version.js` holds the app's version; `scripts/check_app.py` keeps it equal to the release's `VERSION`.
- No API change.
