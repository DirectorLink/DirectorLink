# C4Bridge v0.4.0

Blinds: read the position of every blind in the project and open, close, stop or move it from the API and the web app.

## API

- `GET /v1/blinds` — every blind with its room and position (`room_id` filter)
- `GET /v1/blinds/{blindId}` — one blind
- `PATCH /v1/blinds/{blindId}` with `{"position": 0..100}` — 0 closed, 100 open
- `POST /v1/blinds/{blindId}/stop` — stop a moving blind
- `position` is `null` when the controller does not know it (for example after a reboot, until the blind moves or reports its KNX status).
- Devices of type `blind` (previously `cover`) link to `/v1/blinds/{id}`; `/v1/system` counts `inventory.blinds`.

C4Bridge uses the Control4 blind proxy's own commands, so any blind driver works (KNX, Somfy, …). Blinds without percentage control on the KNX side close at 0 and open fully for any other value; blinds without a KNX stop address ignore stop.

## Web app

- A **Blinds** section with Close / Stop / Open and a position slider.
- Reloading the page reconnects with the saved key instead of waiting for **Connect** (released to the web app already).

## Installing

Update the driver in Composer (no remove and re-add needed from 0.3.0). The **Inventory** property now also counts blinds.

## Known issues

- Updating the driver may still need a Director reboot before the new version loads (issue #8).
- KNX percentage dimming remains deferred (issue #11).
