# C4Bridge v0.5.0

Cameras: see every camera in the project from the API and the web app.

## API

- `GET /v1/cameras` — every camera with its room (`room_id` filter)
- `GET /v1/cameras/{cameraId}` — one camera
- `GET /v1/cameras/{cameraId}/snapshot?width=640` — the current picture (JPEG); widths 320, 640, 1280, 1920
- Devices of type `camera` link to `/v1/cameras/{id}`; `/v1/system` counts `inventory.cameras`.

C4Bridge asks the Control4 camera proxy for the camera's address, login and snapshot path — the same way the Control4 apps do — and fetches the picture on the controller. Camera passwords and addresses never reach the browser. Basic and digest logins are supported, so it works with any camera driver (Hikvision, DoorBird, …).

At most 3 pictures are fetched at a time; when more than 12 are waiting the API answers `503` with `Retry-After: 1`, so cameras never slow down lights and blinds.

## Web app

A **Cameras** grid: pictures refresh every few seconds while visible; tap one to watch it larger (about once a second). Refreshing pauses while the page is hidden.

## Installing

Update the driver in Composer; it loads without a reboot. The **Inventory** property now also counts cameras.

## Known issues

- Snapshots are near-live pictures, not video. Browsers cannot play the cameras' RTSP streams.
- KNX percentage dimming remains deferred (issue #11).
