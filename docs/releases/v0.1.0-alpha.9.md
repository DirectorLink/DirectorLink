# C4Bridge v0.1.0-alpha.9

First Thermostat V2 / HVAC control build.

## Real Director command capture

The Control4 UI was captured controlling a real Thermostat V2 proxy with:

```text
SET_MODE_HVAC
MODE = Off | Heat | Cool

SET_MODE_FAN
MODE = Low | Medium | High

SET_SETPOINT_SINGLE
CELSIUS = 21.0 | 22.0
```

Director forwarded these commands to the existing HVAC protocol driver and updated thermostat state.

## Climate adapter

C4Bridge now recognizes `thermostatv2.c4i/.c4z` proxies and reads current temperature, target setpoint, HVAC mode, fan mode, HVAC state, connection state, and allowed HVAC modes.

Normalized C4Bridge actions:

- `set_hvac_mode`
- `set_fan_mode`
- `set_temperature`

Raw Control4 command names remain internal.

## API

New endpoint: `GET /v1/climate`

Climate actions use the existing normalized device action route.

## PWA

The live project page now includes an HVAC panel with state, HVAC mode, fan mode where supported, target Celsius control, and refresh.

## Scope

KNX percentage dimming remains deferred in issue #11. Light On/Off and owner pairing are already validated.
