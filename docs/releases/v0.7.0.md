# C4Bridge v0.7.0

Key roles and a Door Control switch — the groundwork for family members and remote access.

## Roles

Every API key now has a role; each can do everything the ones before it can:

| Role | Can |
| --- | --- |
| `viewer` | read everything, including camera pictures |
| `member` | also switch lights, change thermostats, move blinds |
| `doors` | also open doors and gates |
| `admin` | also manage API keys, room names and the log |

- Keys created before 0.7.0 become `admin`, so nothing you use stops working.
- The Composer pairing code gives `admin`. An access request gives `admin` to a home's first key and `member` after that; a client can ask for another role with `{"role": "viewer"}`. Composer's **Access Request** shows the role before you press **C4Bridge Access**.
- `GET /v1/api-keys/current` — a client's own key and role. `PATCH /v1/api-keys/{keyId}` — rename a key or change its role (the last admin key cannot be demoted).
- Using something a key may not do answers `403 FORBIDDEN` with `role` and `required_role`. Every operation lists its role in the API description (`x-c4bridge-role`).

## Door Control

A new C4Bridge property in Composer, **Door Control**, is **Disabled** by default: until you set it to **Enabled**, opening doors and gates from the API answers `403 DOOR_CONTROL_DISABLED`, whatever the key's role.

## New web app (app.c4bridge.io)

- Rooms first, with a favorites strip; tabs for Home, Cameras, Climate and Settings; room screens with lights, climate, blinds, doors & gates and cameras.
- Five color palettes, Light / Dark / Auto, English and Hebrew (right to left), room names per language — all in Settings.
- Follows the key's role: view-only keys see states without controls, "Open" only for door access, room renaming only for admins; clear messages when something is not allowed or Door Control is off.
- One slow answer no longer shows the controller as disconnected; camera pictures now show on the hosted site (its security headers blocked them).

## Installing

Update the driver in Composer; it loads without a reboot. **After updating, set Door Control to Enabled** if you open doors from the web app.

## Known issues

- Only relay 1 of each KNX Contact/Relay device is controlled.
- KNX percentage dimming remains deferred (issue #11).
