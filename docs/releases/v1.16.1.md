# DirectorLink v1.16.1

**Direct to Director. End-to-end integration. Open source.**

Disarm works on the first tap during an exit delay, and the countdown counts.

DirectorLink is an independent project, not affiliated with Control4 or Snap One.

## Fixed

- **Disarm during an entry or exit delay.** The app redrew the whole Home screen after each tap while a delay counted down, because the seconds left had changed. The Disarm button under your finger was replaced, so the tap was lost and you had to press several times. Now the seconds are counted down in place and the buttons stay put.
- **The countdown counts.** It used to move only every 10 s or when you tapped; now it moves every second.

## The alarm's code with DirectorLink · PIMA FORCE

1.16.0 sealed the code to DirectorLink · PIMA FORCE 1.2.0, so that Control4's debug log never saw it. On a controller, opening it in the PIMA driver took about 14 seconds a command, and Control4 waited meanwhile. **DirectorLink · PIMA FORCE 1.2.2** takes the typed code again, as with 1.15.0; its "DirectorLink Without Code" is gone, so each arm and disarm asks for your code. The app's Settings → Alarm says so. Like any command between Control4 drivers, the code passes through Control4's debug log, which only the controller's root user can read and which is gone within a few hours.

## Installing

- **DirectorLink in Composer:** update it to 1.16.1 (nothing changed in the driver but its version).
- **DirectorLink · PIMA FORCE:** update it to 1.2.2.
- **The app** updates by itself.
